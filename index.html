🔔 별명으로 멘션하기 (ID 저장)

@사용자명은 그대로 멘션이 됩니다. 별명·한글 이름으로 멘션하려면 이름과 사용자명 또는 사용자 ID를 저장해 두십시오. 그 이름을 쓰면 진짜 멘션으로 들어갑니다.

사용자명·ID는 어디서 봅니까?
  1. 사용자명: 디스코드에서 상대 프로필을 누르면 별명 아래에 보이는 영문 아이디입니다 (예: liberali0_). 역할·채널은 이름을 그대로 넣습니다.
  2. 사용자 ID(숫자): 설정 → 고급 → 개발자 모드를 켜고, 대상을 우클릭(모바일은 길게 누르기) → ID 복사. 역할은 서버 설정 → 역할에서 우클릭합니다.

저장한 목록은 이 브라우저에만 남습니다.

빠르게 넣기

이름으로 넣는 멘션은 디스코드 아이디(사용자명 또는 사용자 ID)와 정확히 같아야 알림이 갑니다. 별명이나 한글 이름으로 쓰려면 위에 저장하십시오.

편집기와 실시간으로 같이 바뀝니다. 디스코드 메시지를 통째로 붙여 넣어도 됩니다. ␛는 색 정보 표시입니다.

사용법과 단축키

사용법

  1. 그냥 쓰고, 꾸밀 글자를 드래그하면 미니 툴바가 뜹니다.
  2. 줄 맨 앞에서 /를 누르면 제목·목록·코드블록·타임스탬프 메뉴가 열립니다.
  3. 다 쓰면 디스코드용으로 복사를 누르고 디스코드에 붙여 넣습니다.
  4. @사용자명이나 #채널을 쓰거나 붙여 넣으면 멘션으로 넣을지, 글자로 둘지 고르는 창이 뜹니다. Tab·Enter는 멘션, Space·Esc는 글자입니다.
  5. 디스코드 메시지를 붙여 넣으면 서식이 살아난 채로 들어옵니다.
